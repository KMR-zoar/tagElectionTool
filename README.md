# プロフタグ総選挙 集計ツール

配信の「プロフタグ総選挙」企画で、リスナーからの投票（ギフトポイント）をタグ別・リスナー別に集計するためのシングルページWebアプリです。サーバー不要、ブラウザの `localStorage` だけで動作します。

## 主な機能

- **投票登録**: タグ・リスナー名・ポイント数（直接入力 or 単価×コンボ数）を入力して投票を記録
- **タグ未確定登録**: タグが決まっていない投票を「未分類」として保留し、後からタグを割り当てて確定
- **端数（繰り越し）管理**: 投票単位ポイントに満たない端数ポイントをリスナーごとに繰り越して集計
- **集計表示**: タグ別ランキング、リスナー別集計、端数一覧、未分類一覧をタブで表示
- **投票履歴の編集・取り消し**: 直前の登録の取り消し、過去の投票の編集・削除
- **投票単位ポイントの変更**: 投票単位ポイント（何ptで1票か）を管理画面から変更（履歴付き）
- **ランキング画像出力**: タグ得票上位15件をCanvasで画像化し、保存・共有
- **全データリセット**: 投票ログ・集計・リスナー状態・匿名連番の一括削除

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面構造（入力・集計・管理の3タブ構成） |
| `app.js` | アプリのロジック一式（データ永続化、集計計算、UI制御、画像出力など） |
| `style.css` | スタイル定義 |
| `tags.json` | タグ候補のマスタデータ（タグ名・読み・カテゴリ） |

## 使い方

1. このディレクトリをそのままWebサーバーで配信するか、`index.html` をブラウザで直接開きます。
   - `tags.json` を `fetch` で読み込むため、`file://` から直接開くとブラウザによっては読み込みに失敗する場合があります。その場合は簡易サーバーを立ち上げてください。

     ```bash
     python3 -m http.server 8000
     ```

     その後ブラウザで `http://localhost:8000/` にアクセスします。
2. 「入力」タブから投票を登録します。
3. 「集計」タブでタグ別・リスナー別の集計結果を確認します。
4. 「管理・設定」タブで投票単位ポイントの変更、履歴の確認・編集、ランキング画像の出力、データのリセットができます。

## データ保存について

投票データや設定はすべてブラウザの `localStorage` に保存されます。サーバーへの送信は行われないため、ブラウザやデバイスを変えると引き継がれません。データを保持したい場合は同一ブラウザ・同一端末で継続して利用してください。

## AI利用について

本リポジトリのコードの一部は、Claude Code（Anthropic）を利用して生成・編集されています。
