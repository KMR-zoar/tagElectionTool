# タグ定義エディタ

リポジトリ直下の `tags.json`(タグ名・よみ・カテゴリ)をブラウザから加除・修正するローカル専用ツールです。

## 起動

```bash
npm run edit
# または
node edit/server.js --port 5501
```

ブラウザで `http://127.0.0.1:5501/` を開きます(既定ポートは Live Server の 5500 と重ならない 5501)。

- 依存パッケージは不要で、Node.js の標準モジュールだけで動作します。
- サーバーは `127.0.0.1` にのみ bind するため、同じPCの外からは接続できません。
- Live Server などの静的サーバーで `edit/index.html` を開いても保存はできません(書き込み API は `server.js` だけが提供します)。

## 機能

- タグの一覧表示、タグ名・よみでの検索、カテゴリでの絞り込み
- タグの追加・編集・削除、↑↓による並べ替え(ファイル内の順序が集計ツールの候補表示順になります)
- 「tags.json に保存」で `tags.json` を直接上書き(既存ファイルの改行コードを維持し、2スペースインデントで出力)
- 保存前の検証: タグ名の空・重複、よみの空、カテゴリなしはエラーとして保存不可。よみにひらがな以外が含まれる場合は警告のみ

## 注意

- タグ名を変更・削除しても、集計ツールの投票ログ(ブラウザの `localStorage`)に記録済みの旧タグ名は自動では置き換わりません。保存時に確認ダイアログで該当タグを表示します。
- 保存は即座に `tags.json` を上書きします。保存後は `git diff tags.json` で差分を確認してください。
- 集計ツール本体を Live Server で開いている場合、`tags.json` の更新を検知して本体が自動でリロードされます。
